数据集使用DeepPCB，地址：https://github.com/tangsanli5201/DeepPCB#

DeepPCB数据集介绍

DeepPCB 是一个 template-based PCB 缺陷检测数据集，每个样本由一张无缺陷模板图像、一张待检测图像以及对应的缺陷边界框标注组成。缺陷标注仅针对测试图像，采用左上–右下角矩形框格式，涵盖 6 类典型 PCB 缺陷。

  1. 克隆数据集
git clone https://github.com/tangsanli5201/DeepPCB.git
  1. 下载成功后的，仓库数据结构
DeepPCB/
├── PCBData/               # 图像 + 标注
├── tools/                 # 辅助工具（如标注或预处理脚本）
├── evaluation/            # 评估脚本 + ground truth
├── fig/                   # README 示例图
└── README.md
  1. 主要使用PCBData中的图像和标注

官方标注类别定义

ID 类别名 含义
0 background 背景（不会出现在标注中）
1 open 断路
2 short 短路
3 mousebite 鼠咬
4 spur 毛刺
5 copper 多余铜
6 pin-hole 针孔

将DeepPCB 数据集转换为 YOLOv8 格式

转换脚本

import os
import cv2
import shutil
from sklearn.model_selection import train_test_split

# --- 配置路径 (请根据你的实际路径调整) ---
src_root = '/home/guodun/rk3588/DeepPCB/PCBData'
dst_root = '/home/guodun/rk3588/DeepPCB/yolo_dataset'

def convert_coordinates(size, box):
    dw = 1. / size[0]
    dh = 1. / size[1]
    x = (box[0] + box[2]) / 2.0
    y = (box[1] + box[3]) / 2.0
    w = box[2] - box[0]
    h = box[3] - box[1]
    return (x * dw, y * dh, w * dw, h * dh)

def process_list(file_list, save_stage):
    img_save_dir = os.path.join(dst_root, 'images', save_stage)
    lbl_save_dir = os.path.join(dst_root, 'labels', save_stage)
    os.makedirs(img_save_dir, exist_ok=True)
    os.makedirs(lbl_save_dir, exist_ok=True)

    missing_count = 0
    for line in file_list:
        parts = line.strip().split()
        if len(parts) < 2: continue
        
        img_rel_path, lbl_rel_path = parts[0], parts[1]
        
        # --- 核心修正：处理文件名后缀问题 ---
        img_path = os.path.join(src_root, img_rel_path)
        
        # 如果 txt 里写的是 .jpg 但磁盘上是 _test.jpg，自动补全
        if not os.path.exists(img_path):
            potential_path = img_path.replace('.jpg', '_test.jpg')
            if os.path.exists(potential_path):
                img_path = potential_path
            else:
                print(f"警告: 找不到图片 {img_path}")
                missing_count += 1
                continue

        lbl_path = os.path.join(src_root, lbl_rel_path)
        if not os.path.exists(lbl_path):
            print(f"警告: 找不到标注 {lbl_path}")
            continue

        # 获取保存文件名
        file_name = os.path.basename(img_path).replace('.jpg', '')
        
        # 1. 复制图片
        shutil.copy(img_path, os.path.join(img_save_dir, f"{file_name}.jpg"))
        
        # 2. 转换标注
        img = cv2.imread(img_path)
        h, w, _ = img.shape
        
        yolo_annotations = []
        with open(lbl_path, 'r') as f:
            for l in f.readlines():
                data = list(map(int, l.strip().split()))
                if len(data) < 5: continue
                x1, y1, x2, y2, cls_id = data
                yolo_box = convert_coordinates((w, h), (x1, y1, x2, y2))
                # 类别转为从 0 开始 (DeepPCB 1-6 -> YOLO 0-5)
                yolo_annotations.append(f"{cls_id-1} {' '.join([f'{a:.6f}' for a in yolo_box])}")
        
        with open(os.path.join(lbl_save_dir, f"{file_name}.txt"), 'w') as f:
            f.write('\n'.join(yolo_annotations))
            
    print(f"{save_stage} 处理完成。跳过缺失文件数: {missing_count}")

# --- 主逻辑 ---
if __name__ == "__main__":
    # 读取索引文件
    with open(os.path.join(src_root, 'trainval.txt'), 'r') as f:
        trainval_lines = f.readlines()
    with open(os.path.join(src_root, 'test.txt'), 'r') as f:
        test_lines = f.readlines()

    # 划分训练/验证集 (90% 训练, 10% 验证)
    train_lines, val_lines = train_test_split(trainval_lines, test_size=0.1, random_state=42)

    process_list(train_lines, 'train')
    process_list(val_lines, 'val')
    process_list(test_lines, 'test')

模型训练

环境准备

Ubuntu 22.04
CUDA 11.8   cuDNN 8.x

# 使用conda创建环境，安装相应的库
conda create -n pcb python=3.9 -y
conda activate pcb
pip install torch torchvision torchaudio --extra-index-url https://download.pytorch.org/whl/cu118
pip install ultralytics onnx onnxsim opencv-python

PyTorch yolov8 训练

由于开始训练过程中会加载对应的模型，没有的话会从github下载，如果失败，可以提前下好，执行时指定对应的模型即可。

yolo detect train \
model=~/.config/Ultralytics/weights/yolov8n.pt \
data=pcb.yaml \
epochs=200 \
imgsz=640 \
batch=32 \
device=0 \
workers=8 \
amp=True \
project=DeepPCB_runs \
name=v100_single_gpu

训练结果

训练过程：收敛充分、无过拟合、泛化能力强；

性能指标：精确率 / 召回率拉满，mAP50 接近满分，mAP50-95 达到高水准；
